# Caso de uso 1-1. Gestión de Cuentas y Autenticación
**Pre-condición:** El usuario ha iniciado sesión y es el Admin o un voluntario con capacidad para crear nuevas cuentas.

**Post-condición:** La cuenta de crea correctamente y está lista para usarse.

## Escenario principal:
1. El usuario ha iniciado sesión correctamente.
2. El usuario se encuentra en el sub-menú de "Gestión de Voluntarios".
3. Selecciona el botón de "Nueva cuenta".
4. Rellena los campos obligatorios, selecciona las capacidades del voluntario y guarda los cambios.

## Escenario alternativos:
- 4.a Un campo obligatorio no fue rellenado y se intentan guardar los cambios.
    - 4.a.1 El sistema muestra un mensaje de error indicando el campo que quedó pendiente.
	- 4.a.2 El sistema regresa al usuario al formulario con todos los datos previos y continua cumplimentándolos.

- 4.b Se intenta crear una cuenta con un campo repetido (existe otra cuenta con este dato: correo o dni).
	- 4.b.1 El sistema muestra un mensaje de error indicando el campo que quedó pendiente.
	- 4.b.2 El sistema regresa al usuario al formulario con todos los datos previos y continua cumplimentándolos.

- 4.c Se selecciona como "Otro" el área profesional.
	- 4.c.1 El sistema habilita una caja de texto adicional que permite al usuario especificar el área profesional que no aparece entre las opciones.
	- 4.c.2 El sistema añade esta nueva entrada a las existes en Area Profesional (BD). Esto permite reutilizar la nueva entrada en futuras cuentas.
	- 4.c.3 El sistema guarda el texto especial como el área profesional de ese voluntario. Aparecerá así en la base de datos y en su ficha correspondiente, no como "Otro".


## Casos de prueba:
### Escenario principal:
**Dado** que el usuario ha iniciado sesión, \
**Y** tiene la capacidad de crear nuevas cuentas de voluntarios,\
**Y** se encuentra en el sub-menú "Gestión de Voluntarios",\
**Cuando** selecciona el botón de "Nueva Cuenta",\
**Y** el sistema muestra el formulario a rellenar,\
**Y** se cumplimenta correctamente (definiendo así una contraseña inicial),\
**Entonces** el sistema notifica al usuario de la creación exitosa de la cuenta,\
**Y** actualiza el estado de la cuenta a PENDIENTE_ACTIVACION.

### Escenario alternativo 4.a (campo obligatorio pendiente por rellenar)
**Dado** que el usuario ha iniciado sesión, \
**Y** tiene la capacidad de crear nuevas cuentas de voluntarios,\
**Y** se encuentra en el sub-menú "Gestión de Voluntarios",\
**Cuando** selecciona el botón de "Nueva Cuenta",\
**Y** el sistema muestra el formulario a rellenar,\
**Y** el usuario deja un campo obligatorio sin rellenar e intenta guardar los cambios,\
**Entonces** el sistema muestra un mensaje de error indicando el campo que quedó pendiente,\
**Y** regresa el usuario al formulario con todos los datos previos,\
**Y** permite seguir cumplimentando el formulario.

### Escenario alternativo 4.b (campo dni o correo ya en uso)
**Dado** que el usuario ha iniciado sesión, \
**Y** tiene la capacidad de crear nuevas cuentas de voluntarios,\
**Y** se encuentra en el sub-menú "Gestión de Voluntarios",\
**Cuando** selecciona el botón de "Nueva Cuenta",\
**Y** el sistema muestra el formulario a rellenar,\
**Y** el usuario introduce un correo o dni previamente registrado en el sistema e intenta guardar los cambios,\
**Entonces** el sistema muestra un mensaje de error indicando el campo ya existe en la base de datos (el sistema),\
**Y** regresa el usuario al formulario con todos los datos previos,\
**Y** permite seguir cumplimentando el formulario.

### Escenario alternativo 4.c (area profesional 'Otro')
**Dado** que el usuario ha iniciado sesión, \
**Y** tiene la capacidad de crear nuevas cuentas de voluntarios,\
**Y** se encuentra en el sub-menú "Gestión de Voluntarios",\
**Cuando** selecciona el botón de "Nueva Cuenta",\
**Y** el sistema muestra el formulario a rellenar,\
**Y** el usuario selecciona "Otro" en Área Profesional,\
**Entonces** el sistema habilita una caja de texto adicional que permite al usuario especificar el área profesional que no aparece entre las opciones,\
**Y** al enviar el formulario, el sistema añade esta nueva entrada a las existes en Area Profesional (BD).
**Y** el sistema se asegura que aparezca así en la base de datos y en la ficha de voluntario creada; no como "Otro".
