# Bitácora del Proyecto

Sistema de documentación personal donde recopilo resumes o fichas de aprendizaje de momentos donde tuve que investigar cosas nuevas que valen la pena comentar y recordar tal cual como las aprendí durante el desarrollo del proyecto. El objetivo también es que sirvan como fuente consultable para la memoria final, recopilando decisiones de diseño importantes, recursos usados y fuentes consultadas.
